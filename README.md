# fastvlm-coreai

> FastVLM converted to Apple Core AI `.aimodel` format for Neural Engine (ANE)
> deployment on iOS 27 and macOS 27. Covers 0.5B, 1.5B, and 7B variants.

## Status

- [ ] 1.5B — in progress
- [ ] 0.5B
- [ ] 7B

## Requirements

- macOS 27 beta / iOS 27 beta
- Xcode 27 beta
- Python 3.11 via uv
- coreai-torch (github.com/apple/coreai-torch)
